# MarkLens

**A private, local-first home for your Markdown library.**

Import your Markdown files, folders, or ZIP archives and read, search, organise, and annotate them
in one clean workspace. MarkLens keeps your library in your browser. There is no account, backend, or
upload.

## Features

- Read GitHub-flavoured Markdown with syntax-highlighted code and a navigable table of contents.
- Organise documents into folders and edit them with a built-in Markdown editor.
- Search across your library, and save bookmarks, notes, and reading progress.
- Import Markdown files, folders, or ZIP archives; export documents and back up your library.
- Choose light, dark, or system theme.

## Get started

Requires Node.js 20.19 or later.

```bash
npm install
npm run dev
```

Open the local URL shown in your terminal. To create a production build, run `npm run build`.

## Privacy

Your library is stored locally in your browser and is not uploaded. Clearing browser site data can
remove it, so use the built-in ZIP backup to keep a copy.

Built with React, TypeScript, and Vite. Feedback and contributions are welcome!
